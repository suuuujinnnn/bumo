# 목업 검토 기록

검토일: 2026-09-10

## 기관명·소속 관계와 따뜻한 색상 개편

풀네임 ‘사단법인 경기장애인부모연대 의정부시지회’를 헤더·푸터·소개·문서 제목에 반영했다. 소개와 푸터에 전국 → 경기 → 의정부 소속 관계와 제공받은 외부 링크를 추가했다. 지회는 텍스트로 표현하며 외부 사이트의 실제 내용 확인은 보류했다.

아이보리·살구 바탕, 코랄 주요 버튼과 참여 구역, 노랑·코랄 연결 그림을 적용했다. 함께하기의 연결형 구성과 예시 정보는 유지했다. 8개 화면 × 5개 너비 × 기본/200% 글자 크기의 80개 조합에서 가로 넘침이 없었고, 홈·소개·함께하기의 모바일·데스크톱 접근성 검사 6개 조합에서 위반이 없었다. 모바일 메뉴 Escape, 기관명이 포함된 문서 제목, JavaScript 오류 없음도 확인했다. 검증 스크립트와 화면 캡처는 `.cache/warm-check.cjs`, `.cache/screens/warm-*.png`에 있다.

## 함께하기 최종 선택

사용자가 C안 ‘연결의 이야기’를 확정했다. 비교 UI와 A·B안 전용 스타일을 제거하고 기본 /participate에 C안을 표시한다. 기존 design 쿼리는 화면 선택에 사용하지 않으며, 참여 방법 앵커와 문의 연결을 유지한다. 아래 후보 비교 기록은 선택 전 검증 이력이다.

## 함께하기 디자인 후보 추가

함께하기의 카드 배치를 대체하는 A 캠페인 히어로, B 에디토리얼, C 연결의 이야기 안을 구현했다. 같은 참여 문안을 사용하며 네이티브 라디오로 비교한다. design 쿼리에 선택을 보존하고 회원·후원·캠페인·자원활동의 기존 앵커를 유지한다. 최종 디자인은 사용자가 선택한다.

3개 안을 320·375·768·1440px 및 200% 글자 확대에서 검사한 24개 조합에 가로 넘침이 없었다. 375·1440px의 axe 자동 검사에서 위반이 없었고 후보 키보드 전환, 앵커 포커스, 새로고침 후 선택 유지도 통과했다. 임시 검증 스크립트는 .cache/participate-check.cjs다.

## 소개·헤더 통합

최상단 보조 바와 모바일 중복 바로가기를 제거하고 6개 주 메뉴·검색·후원 및 회원 안내를 유지했다. 소개는 기관 소개 → 비전과 가치 → 연혁 → 조직 → 상담·문의 → 오시는 길 순이다. 연락처·주소·접근 편의 정보의 추후 입력 상태를 유지한다. 홈의 ‘부모연대 만나기’는 소개·문의·방문 안내로 연결한다.

별도 지역 안내 화면은 없으며 기존 /local 주소는 /about으로 replace 이동한다. 기존 contact·directions·introduction 앵커를 보존한다. 모든 공개 내부 링크는 새 주소를 사용한다. 로그인이나 실제 인증은 추가하지 않았다.

통합 후 타입·빌드·린트 통과. 8개 대표 화면을 320·375·768·1024·1440px와 기본/200% 글자 크기로 검사한 80개 조합에서 가로 넘침이 없었다. 홈·소개를 375·1440px에서 axe로 검사한 4개 조합에서 위반이 없었다. 내부 링크 56개, 이전 주소 4개, 문의 포커스, 모바일 메뉴 Escape, 함께하기 후보 3개 유지도 통과했다. 브라우저 JavaScript 오류는 없었다. 임시 스크립트는 .cache/about-check.cjs다.

## 구현 범위

7개 진입 화면과 공통 상세 화면을 제공한다. 활동 5건, 지원정보 10건, 소식 8건, 자료 5건은 모두 예시이며 홈과 내부 화면이 같은 데이터를 사용한다. 실제 기관 정보는 추후 입력으로 표시한다. 의정부장애인부모연대 자체를 소개한다.

백엔드, DB, 로그인, 개인정보 입력·저장, 실제 검색·신청·상담 접수·결제, 지도, 파일 다운로드, 영상 재생, 배포는 구현하지 않았다.

## 전체 페이지 디자인과 탐색 개편

- 홈의 크림·깊은 초록·세이지·살구색·라일락, 곡면과 여백을 모든 목록·안내·상세 화면에 적용했다.
- 공통 페이지 도입부로 제목과 목적을 먼저 보여주고, 화면별로 정보 표현을 달리했다.
- 상단 내비게이션은 6개 페이지 이동 링크로 단순화했다. 분류용 팝오버와 탭처럼 보이는 필터를 제거했다.
- 페이지 내부 필터는 이름이 연결된 네이티브 선택 상자와 라디오 버튼으로 구성했다. 선택 조건·결과 건수·초기화를 표시한다.
- 활동은 사진 영역을 포함하는 카드 그리드다. 실제 사진 대신 ‘활동 사진 · 추후 제공’과 권장 장면을 표시한다. 선택적인 image 속성으로 로컬 사진과 대체 텍스트를 공급할 수 있으며 업로드 기능은 없다.
- 지원정보는 생애주기 → 필요한 도움·안내 종류 → 결과 순서다. 모든 조건은 선택 사항이고 함께 적용된다. URL의 stage·topic·category로 선택 상태를 유지한다.
- 지원정보 카드는 대상과 알아볼 내용을 구분한다. 상세에는 한눈에 보는 안내와 상담 전에 생각해 볼 질문 3개를 제공한다. 실제 자격 판정이나 검증되지 않은 제도 설명은 제공하지 않는다.
- 자료는 책 표지형 카드, 소식은 모집 상태·신청 기간·행사일을 유지한 목록이다.
- 소개에 기관 정보·문의·오시는 길을 통합하고 페이지 내 이동 링크를 제공한다. 함께하기의 디자인 후보 3개는 유지한다.
- 단체명은 텍스트로 표기한다. 다른 지역의 로고·사진·사업명·통계·연락처를 사용하지 않았다. 외부 이미지·글꼴·UI 라이브러리를 추가하지 않았다.
- 홈의 링과 생애주기 SVG는 장식이다. 활동 사진 교체 시 당사자가 의견을 표현하고 지역사회에 동등하게 참여하는 장면을 권장한다.

[복지로 소개](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/intro/intro/info/01/index.html), [정부24 혜택알리미](https://plus.gov.kr/portal/benefitV2/), [KRDS 필터링](https://www.krds.go.kr/html/site/global/global_10.html), [KRDS 상세 검색](https://www.krds.go.kr/html/site/service/service_02_05.html)을 참고했다. 생애주기·상황 중심의 탐색, 명확한 필터 이름, 선택 조건과 결과의 연결을 적용했다. 정부의 시각 정체성이나 실제 서비스 정보를 복제하지 않았다.

## 이전 전체 디자인 개편의 자동·브라우저 검사

프로젝트에 테스트 프레임워크를 추가하지 않고 임시 Playwright·axe-core로 Edge를 헤드리스 실행했다. 스크립트·보고서·캡처는 Git에서 제외한 .cache에 보관한다.

- TypeScript 타입 검사, ESLint, Vite 프로덕션 빌드 통과.
- 320·375·768·1024·1440px에서 14개 주소(진입 화면 8개, 대표 상세 4개, 잘못된 주소 2개), 총 70개 조합: 가로 넘침 없음.
- 기본 루트 글자 크기를 112.5%에서 225%로 확대하여 320·1440px의 12개 화면 검사: 24개 조합에서 가로 넘침 없음.
- axe-core의 WCAG 2 A/AA, 2.1 AA, 2.2 AA 규칙을 320·1440px의 12개 정상 화면에서 실행: 자동 검출 위반 없음.
- 자료 표지의 보조 글자 대비 문제 2건을 발견해 색상을 조정한 뒤 전체 검사를 다시 통과했다.
- 고유 내부 링크 54개의 목적지와 구역 식별자 검사: 끊어진 링크 없음.
- 검사 중 JavaScript 오류와 외부 네트워크 요청 없음.
- 데스크톱과 모바일 캡처로 카드, 필터, 안내·상세 화면의 정보 위계와 줄바꿈을 확인했다.

검사 결과는 .cache/interior-report.json, 시나리오는 .cache/interior-check.cjs에 있다. 이 파일들은 로컬 검증 자료이며 배포물이나 저장소 의존성에 포함하지 않는다.

## 남은 실제 이용자 검토

자동 검사를 KWCAG·WCAG 인증이나 모든 항목의 준수 판정으로 해석하지 않는다.

- [ ] NVDA 또는 VoiceOver의 실제 음성 출력으로 제목·링크 목적·메뉴 상태·필터 건수 안내 확인
- [ ] 실제 브라우저의 글자만 확대 및 페이지 확대에서 읽기 순서·잘림·겹침 확인
- [ ] iOS Safari·Android 실물 기기의 터치와 기기 글자 확대 확인
- [ ] 당사자·가족과 쉬운 표현, 생애주기·도움 분류, 문의 경로 검토
- [ ] 공식 비전·연혁·조직·연락처·주소·방문 접근성 정보 확인
- [ ] 공식 사진의 사용 범위와 대체 텍스트 검토
- [ ] 실제 콘텐츠 교체 후 긴 제목·다양한 일정·빈 분류 재검증

실제 스크린리더 음성과 실물 모바일 기기는 이번 환경에서 검증하지 않았다.
