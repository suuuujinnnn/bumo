# 목업 검토 기록

검토일: 2026-09-09

## 구현 범위

8개 진입 화면과 홈·목록·상세·안내의 4종 템플릿을 구현했다. 지원정보를 우선으로 탐색하고, 활동·소식·자료·참여 안내를 이어서 확인하는 구조다. 지역 안내는 의정부만 다룬다.

샘플 데이터는 활동 5건, 지원정보 10건, 소식 8건, 자료 5건이다. 홈·목록·상세가 같은 데이터를 사용한다. 게시물과 날짜는 예시이며, 실제 기관 정보는 추후 입력으로 표시한다. 잘못된 주소와 선택한 분류의 결과가 없는 상태도 제공한다.

후원·회원·행사·상담은 안내 단계까지만 제공한다. 개인정보 입력이나 저장, 실제 검색·접수·결제, 지도·파일·영상 서비스, 배포는 없다.

## 시각·콘텐츠 기준

- 단체명은 공식 로고를 대신한 텍스트 표기다. 가짜 로고나 다른 지역의 로고를 사용하지 않았다.
- 크림 배경과 깊은 초록을 기본으로, 세이지·살구색·라일락을 보조색으로 사용한다. 곡선과 여백으로 부드러운 인상을 만들고 긴 정보는 목록으로 정리한다.
- 정보는 짧은 한국어로 작성하고, 당사자의 선택·자립·지역사회 참여·가족의 삶을 중심에 둔다.
- 히어로에는 연결을 상징하는 링 그래픽을, 생애주기에는 간단한 그래픽을 코드 기반 SVG로 작성했다. 모두 장식으로 처리하며 실제 단체의 사진이나 공식 로고로 표현하지 않는다.
- 활동 영역은 색면과 그래픽을 활용한 포스터 형태로 구성하고 ‘활동 사진 · 추후 제공’을 표시한다. 교체할 사진은 당사자와 가족이 의사를 표현하는 모임, 지역사회 참여, 동등한 이웃으로 함께 활동하는 장면을 권장한다.
- 기존 참고 캡처의 사진·사업명·통계·기관 정보를 재사용하지 않았다.
- 시스템 글꼴과 코드로 작성한 기능 아이콘을 사용한다. 외부 폰트·이미지 요청은 없다.

## 자동·브라우저 검사

프로젝트에 테스트 프레임워크를 추가하지 않고, 임시 도구로 Edge를 헤드리스 실행하여 검사했다. 검사 스크립트·도구·캡처는 Git에서 제외한 `.cache/`에 보관했다.

- TypeScript 타입 검사, Vite 프로덕션 빌드, ESLint 검사 통과.
- 320·375·768·1024·1440px에서 14개 주소(진입 화면 8개, 대표 상세 4개, 잘못된 주소 2개), 총 70개 조합 검사: 가로 넘침 없음, 페이지당 h1 하나.
- 기본 루트 글자 크기를 112.5%에서 225%로 확대하여 320·1440px의 12개 화면 검사: 24개 조합에서 가로 넘침 없음.
- axe-core의 WCAG 2 A/AA, 2.1 AA, 2.2 AA 규칙을 320·1440px의 12개 정상 화면에서 실행: 자동 검출 위반 없음.
- 검색 안내 열림, 지원정보 분류 선택, 모바일 전체 메뉴·하위 메뉴 열림의 3개 상태에서도 axe-core 자동 검출 위반 없음.
- 화면에 연결된 고유 내부 링크 70개의 목적지와 구역 식별자를 확인: 끊어진 링크 없음.
- 브라우저 실행 중 JavaScript 오류와 외부 네트워크 요청 없음.
- 데스크톱·모바일의 실제 화면 캡처로 정보 위계와 제목 줄바꿈을 확인했다. 모바일 메인 제목은 주요 행동이 더 빨리 보이도록 크기를 조정했다.

검사에서 검색 대화상자의 마지막 항목 다음에 포커스가 브라우저로 빠질 수 있는 동작을 발견하여 명시적인 Tab 순환 처리를 추가했고 재검사했다.

## 수동 검토 체크리스트

실제 이용자 검토에서는 아래 항목을 다시 확인한다. 자동 검사 결과를 KWCAG·WCAG 인증이나 모든 항목의 준수 판정으로 해석하지 않는다.

- [ ] NVDA 또는 VoiceOver의 실제 음성 출력으로 제목·링크 목적·펼침 상태·필터 건수 안내 확인
- [ ] 실제 브라우저의 글자만 확대 및 페이지 확대에서 읽기 순서·잘림·겹침 확인
- [ ] iOS Safari·Android 브라우저의 터치와 기기 글자 확대 확인
- [ ] 당사자·가족과 함께 쉬운 표현, 생애주기 분류, 문의 경로를 검토
- [ ] 공식 단체명 표기·비전·연혁·조직·연락처·주소·방문 접근성 정보 확인
- [ ] 공식 사진의 사용 범위와 대체 텍스트 검토
- [ ] 실제 콘텐츠로 교체한 뒤 긴 제목·다양한 일정·빈 분류 재검증

실제 스크린리더 음성, 실물 모바일 기기, 모든 브라우저의 수동 검사는 이번 실행 환경에서 수행하지 않았다.

## 홈 디자인 개편

사용자의 피드백에 따라 정보 구성·8개 화면·탐색 경로는 유지하고 홈의 시각 디자인을 전면 개편했다.

- 넓은 곡면 히어로, 큰 제목, ‘연결’을 표현하는 입체감 있는 링 그래픽을 구성했다.
- 데스크톱 헤더를 한 줄로 정돈하고 주요 버튼과 모바일 바로가기를 둥글게 바꿨다.
- 자주 찾는 서비스는 부드러운 보조색 아이콘으로, 활동은 비대칭 포스터 배치로 구분했다.
- 생애주기별 그래픽, 책 형태의 자료 아이콘, 지역 안내 그래픽을 추가했다.
- 외부 이미지·글꼴·라이브러리는 추가하지 않았다. 짧은 마우스 반응만 적용하고 움직임 줄이기 설정을 존중한다.
- 새 배경색에 맞춰 보조 글자의 대비를 수정했다. 개편 후 70개 화면 조합, 24개 글자 확대 조합, 접근성 자동 검사 및 기존 키보드·목록 탐색 검사가 통과했다.
