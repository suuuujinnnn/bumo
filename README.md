# 의정부장애인부모연대 웹 목업

장애인 가족에게 필요한 정보를 연결하고, 장애인의 권리를 함께 만들어가는 정보·연대 플랫폼의 프론트엔드 목업입니다. 정보의 구성과 탐색 경로를 검토하기 위한 화면이며 실제 지원·신청 서비스를 운영하지 않습니다.

## 실행

Node.js 22.12 이상을 사용하세요. 개발·검증 환경은 Node.js 24.20입니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. 개발 서버는 기본적으로 `http://127.0.0.1:5173`에서 실행됩니다.

```sh
npm run typecheck
npm run lint
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. HTTP 정적 서버에서 제공해야 하며 `index.html`을 파일로 직접 여는 방식은 지원하지 않습니다. `HashRouter`와 상대 에셋 경로를 사용하므로 하위 경로에서도 서버의 SPA 경로 재작성 설정 없이 화면 이동·새로고침이 가능합니다.

## 화면과 탐색

| 화면          | 주소             |
| ------------- | ---------------- |
| 메인          | `/#/`            |
| 부모연대 소개 | `/#/about`       |
| 활동          | `/#/activities`  |
| 지원정보      | `/#/support`     |
| 소식·공지     | `/#/news`        |
| 자료실        | `/#/resources`   |
| 의정부 안내   | `/#/local`       |
| 함께하기      | `/#/participate` |

활동·지원정보·소식·자료는 공통 목록과 상세 템플릿을 사용합니다. 분류와 생애주기 선택은 URL 쿼리에 저장되며, 상세의 ‘목록으로’ 링크와 브라우저 뒤로 가기에서도 선택을 유지합니다. 예: `/#/support?stage=학령기`.

검색은 안내 대화상자만 제공합니다. 소개·의정부·함께하기의 하위 메뉴는 같은 페이지의 해당 구역으로 이동합니다. 예: `/#/local#contact`.

## 코드 구성

- `src/components/layout`: 헤더·푸터·전체 메뉴·검색 안내
- `src/components/ui`: 아이콘·섹션 제목·상태·예시 표시·빈 상태
- `src/features`: 콘텐츠 목록·필터와 메인 전용 섹션
- `src/pages`: 홈·목록·상세·안내·잘못된 주소 화면
- `src/data`: 메뉴, 샘플 게시물 28건, 안내 문안
- `src/styles`: CSS 변수, 기본 스타일, 레이아웃·컴포넌트·페이지 스타일
- `docs/mockup-review.md`: 범위, 탐색 시나리오, 검증 결과와 남은 확인 사항

React·TypeScript·Vite·React Router를 사용하며, 별도 UI 라이브러리·상태관리·API 계층은 없습니다. 글꼴과 이미지를 외부 URL에서 불러오지 않습니다.

홈은 크림·초록 중심의 곡선 레이아웃과 코드로 작성한 SVG 그래픽을 사용합니다. `src/features/home/HomeArtwork.tsx`에 히어로·활동·생애주기 그래픽이 있고, `src/styles/home.css`에서 홈 디자인을 관리합니다.

## 콘텐츠 교체 시 주의

- 게시물과 날짜·모집 상태는 모두 고정된 예시입니다. 시간이 지나도 상태가 자동으로 바뀌지 않습니다.
- 실제 주소·전화·이메일·연혁·조직·사업·후원 방법은 확인 후 입력해야 합니다.
- `docs/타사이트*.jpg`는 정보 배치를 참고하기 위한 기존 캡처입니다. 화면에서 불러오거나 의정부의 공식 에셋으로 사용하지 않습니다.
- 활동 사진의 자리표시자는 공식 이미지 확보 후 교체하며, 실제 이미지의 내용을 설명하는 대체 텍스트를 함께 작성해야 합니다.
- 백엔드, DB, 로그인, 실제 검색·접수·결제, 지도, 파일 다운로드, 영상 재생, 배포는 구현 범위에 포함하지 않습니다.
