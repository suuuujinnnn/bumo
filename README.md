# 사단법인 경기장애인부모연대 의정부시지회 웹 목업

기관 풀네임을 헤더·푸터·소개·페이지 제목에 반영했습니다. 소개와 푸터에서 전국 → 경기 → 의정부시지회 소속 관계와 각 사이트·다음 카페 링크를 제공합니다. 별도 지회 로고 대신 텍스트로 기관을 표시합니다. 밝은 아이보리·살구색 바탕과 코랄·노랑 포인트를 사용하며, 기존 함께하기의 연결형 구성과 예시 데이터는 유지합니다. 외부 사이트 내용 검증은 추후 진행합니다.

장애인 가족에게 필요한 정보를 연결하고, 장애인의 권리를 함께 만들어가는 정보·연대 플랫폼의 프론트엔드 목업입니다. 정보의 구성과 탐색 경로를 검토하기 위한 화면이며 실제 지원·신청 서비스를 운영하지 않습니다.

## 실행

Node.js 22.12 이상을 사용하세요. 개발·검증 환경은 Node.js 24.20입니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. 개발 서버는 기본적으로 `http://127.0.0.1:5173`에서 실행됩니다.

```sh
npm run typecheck
npm run lint
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. HTTP 정적 서버에서 제공해야 하며 `index.html`을 파일로 직접 여는 방식은 지원하지 않습니다. `HashRouter`와 상대 에셋 경로를 사용하므로 하위 경로에서도 서버의 SPA 경로 재작성 설정 없이 화면 이동·새로고침이 가능합니다.

## 화면과 탐색

| 화면          | 주소             |
| ------------- | ---------------- |
| 메인          | `/#/`            |
| 부모연대 소개 | `/#/about`       |
| 활동          | `/#/activities`  |
| 지원정보      | `/#/support`     |
| 소식·공지     | `/#/news`        |
| 자료실        | `/#/resources`   |
| 함께하기      | `/#/participate` |

활동은 사진 중심 카드, 자료는 책 표지형 카드, 소식은 일정과 상태를 보여주는 목록으로 구성합니다. 지원정보는 생애주기·필요한 도움·안내 종류를 선택하는 전용 탐색 화면입니다. 상세 화면은 공통 구조를 사용하되 콘텐츠 종류에 맞는 안내를 제공합니다.

상단 메뉴는 팝오버 없이 6개 페이지로 바로 이동합니다. 페이지 내부 분류는 라디오 버튼과 선택 상자로 표시하며 탭으로 표현하지 않습니다. 지원정보의 `stage`, `topic`, `category`는 함께 적용되고 URL에 저장됩니다. 상세의 목록 복귀와 브라우저 뒤로 가기에서도 선택을 유지합니다. 예: `/#/support?stage=학령기`. 조건 초기화와 빈 결과 안내도 제공합니다. 실제 지원 자격을 판정하는 기능은 없습니다.

검색은 안내 대화상자만 제공합니다. 소개 페이지의 ‘이 페이지에서’ 링크는 해당 구역으로 이동합니다. 예: `/#/about#contact`.

상단 보조 바와 모바일 중복 바로가기를 제거했습니다. 의정부장애인부모연대 자체의 소개, 비전·가치, 연혁, 조직, 상담·문의, 오시는 길을 `/#/about`에 통합합니다. 이전 `/#/local`은 소개로 자동 이동하며, `#contact`·`#directions`·`#introduction`도 새 소개의 해당 구역으로 연결합니다. 로그인·인증 기능은 없습니다.

## 코드 구성

- `src/components/layout`: 헤더·푸터·전체 메뉴·검색 안내
- `src/components/ui`: 공통 페이지 도입부·생애주기 그림·아이콘·제목·상태·빈 상태
- `src/features`: 활동·자료 카드, 소식 목록, 분류 필터, 지원정보 카드와 홈 섹션
- `src/pages`: 홈·목록·지원정보 탐색·상세·안내·잘못된 주소 화면
- `src/data`: 메뉴, 샘플 게시물 28건, 지원정보별 대상·준비 질문, 안내 문안
- `src/styles`: CSS 변수, 기본 스타일, 레이아웃·컴포넌트·페이지 스타일
- `docs/mockup-review.md`: 범위, 탐색 시나리오, 검증 결과와 남은 확인 사항

React·TypeScript·Vite·React Router를 사용하며, 별도 UI 라이브러리·상태관리·API 계층은 없습니다. 글꼴과 이미지를 외부 URL에서 불러오지 않습니다.

전체 화면은 크림·초록 중심의 곡선 레이아웃과 코드로 작성한 SVG 그래픽을 사용합니다. 홈 그래픽은 `src/features/home/HomeArtwork.tsx`, 공유 생애주기 그림은 `src/components/ui/LifeStageArtwork.tsx`에 있습니다. `src/styles/home.css`는 홈, `src/styles/pages.css`는 내부 화면을 관리합니다.

## 콘텐츠 교체 시 주의

함께하기는 확정된 ‘연결의 이야기’ 디자인을 사용합니다. 연결선을 따라 글과 그림을 교차 배치하며, 모바일에서는 한 줄로 읽습니다. 후보 선택 UI는 제거했습니다. 이전 design 쿼리 주소도 같은 화면을 표시합니다. 구현은 `src/pages/ParticipatePage.tsx`, 스타일은 `src/styles/participate.css`에 있습니다.

- 게시물과 날짜·모집 상태는 모두 고정된 예시입니다. 시간이 지나도 상태가 자동으로 바뀌지 않습니다.
- 실제 주소·전화·이메일·연혁·조직·사업·후원 방법은 확인 후 입력해야 합니다.
- `docs/타사이트*.jpg`는 정보 배치를 참고하기 위한 기존 캡처입니다. 화면에서 불러오거나 의정부의 공식 에셋으로 사용하지 않습니다.
- 활동 사진의 자리표시자는 공식 이미지 확보 후 게시물의 선택 속성 `image: { src, alt }`로 교체할 수 있습니다. 로컬 에셋 경로와 실제 장면을 설명하는 대체 텍스트를 사용합니다. 파일 업로드 기능은 없습니다.
- 백엔드, DB, 로그인, 실제 검색·접수·결제, 지도, 파일 다운로드, 영상 재생, 배포는 구현 범위에 포함하지 않습니다.
